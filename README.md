# calculadoraHidrica

Calculadora para la interpretación de relaciones iónicas (hidroquímica) — Facultad de Ciencias Exactas y Naturales.
Sitio estático: se ejecuta en el navegador, sin servidor ni instalación.

## Archivos
- `index.html`, `styles.css` — interfaz.
- `js/calculos.js` — cálculos e informe (equivalente al programa en Python).
- `js/app.js` — formulario, resultados y botones del menú.
- `assets/logo-fceyn.png` — logo de la Facultad.

Referencia: Mariño, E. E. y Willging, P. A. (2024). Desarrollo de una herramienta para la interpretación de relaciones hidroquímicas. En: Aguas subterráneas: Retos para una gestión sostenible. EdUNLPam, Tomo II: 140-147.
